# Post-launch SEO growth roadmap

Status: **START AFTER MIGRATION STABILITY**

No Search Console performance export was available locally, so this roadmap does not invent queries,
clicks, positions or conversions.

## First 14 days: preserve

- Monitor Search Console indexing, sitemap processing, canonical selection and crawl errors daily.
- Compare indexed retained URLs with the 32-URL sitemap; investigate unexpected WordPress/demo URLs.
- Check priority pages in order: aircond, renovation, demolition planning, electrical,
  waterproofing and plaster ceiling.
- Monitor 301/410/404 and server error logs; correct only verified migration issues.
- Validate real enquiries and the three approved event types without treating clicks as completed
  jobs.
- Keep Google Business Profile details consistent with the website after owner approval.

## Days 15–45: strengthen trust and local relevance

- Add verified project media with locations, service type, date and owner-approved captions.
- Publish genuine before/after case studies for aircond and renovation first.
- Request and respond to genuine customer reviews; never manufacture reviews.
- Improve internal links from relevant guides to service pages and from service pages to verified
  case studies.
- Refresh FAQ answers using real customer questions, quotation boundaries and site constraints.
- Review image filenames, dimensions, compression, alt text and page context.
- Monitor Core Web Vitals by template and fix measured regressions.
- Audit consistent name, address and phone details across real local citations.

## Days 46–90: expand measured opportunities

- Use Search Console landing-page/query data to identify page-two rankings, lost queries and
  cannibalisation before changing content.
- Compare genuine competitor coverage for service-area intent, evidence, FAQs and project proof.
- Improve conversion paths based on validated form completion and contact-click behaviour.
- Refresh content where facts, prices, dates or processes are genuinely outdated.
- Build service-area relevance through useful evidence, not thin location-page duplication.

## Priority workstreams

1. **Aircond:** protect approved owner media, strengthen installation/servicing distinctions, and
   create verified case studies.
2. **Renovation:** add genuine scopes, property types, site constraints and project evidence.
3. **Demolition:** plan a new page only after migration is stable and the owner confirms services,
   licensing/approval boundaries, debris handling, areas, safety process and authentic media.
4. **Electrical:** strengthen safety/process content without making unsupported credentials claims.
5. **Waterproofing:** use verified leak diagnosis and repair examples; avoid guarantee claims.
6. **Plaster ceiling:** add authentic ceiling, lighting and aircond-access project examples.

## Demolition page gate

Do not create the page during Phase 6. First confirm business capability, exact work types, service
areas, approval responsibilities, waste handling, quotation inputs, insurance/credential facts and
project media. Then use Search Console/competitor-gap evidence to define one useful page rather than
multiple thin location variants.
